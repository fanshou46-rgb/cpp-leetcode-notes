# C++ 单调栈基础

单调栈本质上仍然是普通栈，只是在入栈前不断弹出不满足单调性的元素，使栈内对应的值保持递增或递减关系。

## 一、适用场景

最典型的问题是：

```text
对每个元素，寻找左边或右边第一个更大 / 更小的元素
```

看到“左边 / 右边”“第一个 / 最近的”“更大 / 更小”这些关键词时，可以优先考虑单调栈。

## 二、为什么常存下标

很多题不仅需要知道匹配到的值，还需要修改某个位置的答案，因此栈中通常保存下标：

```cpp
stack<int> st;
```

通过：

```cpp
prices[st.top()]
```

即可取得栈顶下标对应的值。

## 三、基本模板

```cpp
for (int i = 0; i < n; i++) {
    while (!st.empty() && 当前元素能够解决栈顶元素) {
        int j = st.top();
        st.pop();

        // 用当前元素处理位置 j 的答案
    }

    st.push(i);
}
```

一个当前元素可能一次解决多个旧元素，因此通常需要 `while` 而不是 `if`。

## 四、1475：右边第一个小于等于当前值

可以先令：

```cpp
vector<int> ans = prices;
```

栈保存还没找到折扣的商品下标：

```cpp
for (int i = 0; i < prices.size(); i++) {
    while (!st.empty() && prices[i] <= prices[st.top()]) {
        int j = st.top();
        st.pop();
        ans[j] = prices[j] - prices[i];
    }

    st.push(i);
}
```

若某个下标一直留在栈里，说明右边不存在满足条件的折扣，因此保留原价即可。

## 五、复杂度为什么是 O(n)

虽然代码形式是 `for + while`，但每个下标最多：

```text
push 一次
pop 一次
```

因此总栈操作次数最多约为 `2n`，整体时间复杂度仍为：

```text
O(n)
```

这种计算方式属于摊还分析。

## 六、常见方向

入门时可以先记：

```text
找更小 -> 常维护递增栈
找更大 -> 常维护递减栈
```

但最终应根据“谁在等待谁来解决”以及遍历方向决定具体单调性。

## 八、1019：链表中的下一个更大节点

题目要求每个节点右侧第一个严格更大的节点。扫描链表时，当前节点负责解决前面还没有找到答案的较小节点。

栈保存节点值和节点下标：

~~~cpp
stack<pair<int, int>> st;
while (!st.empty() && cur->val > st.top().first) {
    int index = st.top().second;
    st.pop();
    ans[index] = cur->val;
}
st.push({cur->val, index});
~~~

栈中的值保持单调递减。每个节点最多入栈一次、出栈一次，因此时间 O(n)，空间 O(n)。其核心模型与 739 每日温度相同。
