# C++ 位运算知识手册

> 记录按位运算的基本规则、常见算法技巧、补码原理与刷题应用。

## 一、二进制基础

计算机中的整数可以表示为二进制。例如：

```text
12 = 00001100
10 = 00001010
```

最右边为第 0 位，从右向左依次是第 1 位、第 2 位等。第 k 位对应的数值是 2 的 k 次方。

位运算把整数看成二进制位序列，对对应位置进行操作。

## 二、六种常用位运算符

| 运算符      | 名称   | 规则           |
| -------- | ---- | ------------ |
| `&`      | 按位与  | 两位都为 1 才为 1  |
| `&#124;` | 按位或  | 至少一位为 1 就为 1 |
| `^`      | 按位异或 | 两位不同为 1      |
| `~`      | 按位取反 | 0 变 1，1 变 0  |
| `<<`     | 左移   | 二进制向左移动      |
| `>>`     | 右移   | 二进制向右移动      |

### 1. 按位与

```text
  12 = 00001100
  10 = 00001010
       --------
12&10= 00001000 = 8
```

常用于检查某一位是否为 1，或清除指定的位。

### 2. 按位或

```text
  12 = 00001100
  10 = 00001010
       --------
12|10= 00001110 = 14
```

常用于把指定位置设置为 1。

### 3. 按位异或

```text
  12 = 00001100
  10 = 00001010
       --------
12^10= 00000110 = 6
```

异或的核心性质：

```text
a ^ a = 0
a ^ 0 = a
a ^ b ^ a = b
```

异或满足交换律和结合律，所以相同数字即使不相邻，也可以成对抵消。

注意：C++ 中 `^` 不是乘方。

### 4. 按位取反

取反会交换所有二进制位的 0 和 1。

在固定 8 位宽度下：

```text
 12 = 00001100
~12 = 11110011
```

但 C++ 中 `int` 通常为 32 位，直接计算 `~12` 在常见补码实现下得到 -13，而不是 243。

如果只想保留最低 8 位，可以使用掩码：

```cpp
unsigned int x = 12;
unsigned int y = (~x) & 0xFFu;
```

其中 `0xFF` 的二进制是 `11111111`。

### 5. 左移与右移

对于非负整数，在移位有效且不发生溢出的条件下：

```cpp
12 << 1;  // 24
12 << 2;  // 48
12 >> 1;  // 6
12 >> 2;  // 3
```

左移 k 位对应乘以 2 的 k 次方；右移 k 位对应除以 2 的 k 次方并舍去余数。

处理负数、符号位或较大移位次数时，应更加谨慎。纯位掩码操作优先考虑无符号整数。

## 三、位掩码（Mask）

位掩码是用来选择指定二进制位的数字。

第 k 位的掩码：

```cpp
1u << k
```

例如：

```text
1u << 3 = 00001000
```

### 检查第 k 位

```cpp
bool bit = (x & (1u << k)) != 0;
```

### 设置第 k 位为 1

```cpp
x |= (1u << k);
```

### 清除第 k 位为 0

```cpp
x &= ~(1u << k);
```

### 翻转第 k 位

```cpp
x ^= (1u << k);
```

### 读取第 k 位的 0 或 1

```cpp
unsigned int bit = (x >> k) & 1u;
```

使用 `1u` 是为了采用无符号整数进行掩码计算。移位次数必须小于类型的位宽。

## 四、原码、反码与补码

以下使用 8 位二进制举例。

### 1. 原码

最高位表示符号，其余位表示数值大小。

```text
+12 原码：00001100
-12 原码：10001100
```

### 2. 反码

正数的反码与原码相同。负数的反码保持符号位为 1，其余位取反。

```text
-12 原码：10001100
-12 反码：11110011
```

### 3. 补码

负数的补码等于反码加 1。

```text
-12 反码：11110011
          +       1
          --------
-12 补码：11110100
```

对于固定宽度的补码整数，也可以直接理解为：正数按位取反，再加 1，得到其相反数的补码表示。

现代主流计算机采用补码表示有符号整数。

## 五、Lowbit：提取最低位的 1

常用公式：

```cpp
lowbit = x & -x;
```

例如：

```text
 x = 12 = 00001100
-x      = 11110100
          --------
结果     = 00000100 = 4
```

这里的结果是一个只保留最低有效 1 的掩码，而不一定是数值 1。

### 补码原理推导

假设非零整数 x 的二进制形式为：

```text
x = A 1 000...000
```

中间的 1 是最低位的 1，它的右边全部是 0。

按位取反：

```text
~x = ~A 0 111...111
```

再加 1：

```text
-x = ~A 1 000...000
```

末尾连续的 1 加 1 后全部变为 0，进位恰好停在原来最低位的 1 上。

最后按位与：

```text
 x =  A 1 000...000
-x = ~A 1 000...000
     ----------------
 & =  0 1 000...000
```

高位 A 与 ~A 按位与全部为 0，右边也全是 0，只有最低位的那个 1 被保留。

因此，`x & -x` 能提取最低有效的 1。

对于非零且不会发生取负溢出的有符号整数，可以直接使用该写法。通用位运算中可以使用无符号版本：

```cpp
unsigned int u = static_cast<unsigned int>(x);
unsigned int lowbit = u & (0u - u);
```

## 六、其他常用位运算技巧

### 1. 判断奇偶

```cpp
if (x & 1) {
    // 奇数
} else {
    // 偶数
}
```

奇数的最低位为 1，偶数的最低位为 0。

### 2. 清除最低位的 1

```cpp
x = x & (x - 1);
```

例如：

```text
x     = 00101100
x - 1 = 00101011
        --------
结果   = 00101000
```

最低位的 1 被清除。

### 3. 统计二进制中 1 的个数

```cpp
int countOnes(unsigned int x) {
    int cnt = 0;

    while (x != 0) {
        x &= (x - 1);
        cnt++;
    }

    return cnt;
}
```

每次循环清除一个 1，所以循环次数等于二进制中 1 的个数。

### 4. 判断是否为 2 的幂

```cpp
bool isPowerOfTwo(unsigned int x) {
    return x != 0 && (x & (x - 1)) == 0;
}
```

2 的幂在二进制中恰好只有一个 1。清除这个 1 后，结果为 0。

必须排除 x=0。

## 七、异或找只出现一次的数字

如果数组中只有一个数字出现一次，其他数字都出现两次，可以把所有数字异或。

例如：

```text
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4
```

代码：

```cpp
int singleNumber(vector<int>& nums) {
    int ans = 0;

    for (int x : nums) {
        ans ^= x;
    }

    return ans;
}
```

时间复杂度 O(n)，辅助空间 O(1)。

适用题目：LeetCode 136“只出现一次的数字”。

## 八、异或分组：错误的集合

设重复值为 d，丢失值为 m。

把实际数组与正确集合 1 到 n 的全部数字异或：

```text
X = d ^ m
```

正常数字在两个集合中各出现一次，全部抵消。

因为 d 和 m 不同，所以 X 不为 0。X 中为 1 的某一位，说明 d 和 m 在该位上的值不同。

提取最低位的 1：

```cpp
int lowbit = X & -X;
```

然后按照这一位分组：

```cpp
if (x & lowbit) {
    a ^= x;
} else {
    b ^= x;
}
```

实际数组和正确集合必须使用同一套分组规则。

### 为什么分组后能够分别得到 d 和 m？

1. 相同的正常数字在选定二进制位上完全相同，因此进入同一组。
2. 同一组中的两个相同数字异或后抵消。
3. d 和 m 在选定的二进制位上不同，因此进入不同组。
4. 每组最终只剩下一个目标数字。

例如：

```text
实际数组：[1,2,2,4]
正确集合：[1,2,3,4]

X = 2 ^ 3 = 1
lowbit = 1
```

此时按最低位分组，相当于按奇偶分组。

第一组（奇数）：

```text
1 ^ 1 ^ 3 = 3
```

第二组（偶数）：

```text
2 ^ 2 ^ 4 ^ 2 ^ 4 = 2
```

所以得到两个候选数字 3 和 2。最后扫描原数组，判断哪个出现过，从而确定重复值和丢失值。

注意：分组不一定是按奇偶数。只有 lowbit=1 时，才等价于按奇偶分组。

## 九、按位运算与逻辑运算的区别

| 位运算      | 逻辑运算           | 区别       |
| -------- | -------------- | -------- |
| `&`      | `&&`           | 按位与和逻辑与  |
| `&#124;` | `&#124;&#124;` | 按位或和逻辑或  |
| `~`      | `!`            | 按位取反和逻辑非 |

例如：

```cpp
int a = 2, b = 3;

a & b;   // 结果为 2
a && b;  // 结果为 true
```

逻辑与 `&&` 和逻辑或 `||` 具有短路特性，按位运算没有相同的逻辑短路行为。

引用参数中的 `&` 与表达式中的按位与 `&` 也是不同的语法含义。

## 十、优先级与安全注意事项

位运算表达式建议主动添加括号。

正确写法：

```cpp
if ((x & 1) == 0) {
    // 偶数
}
```

不要写成：

```cpp
if (x & 1 == 0) {
    // 容易因优先级产生错误
}
```

使用位运算时还要注意：

* 不要把 `^` 当作乘方。
* 不要把按位与 `&` 和逻辑与 `&&` 混淆。
* 数组下标计算时要防止越界。
* 移位次数不能达到或超过类型位宽。
* 处理符号位、负数和可能溢出的表达式时，应谨慎选择整数类型。
* 不要为了使用位运算而强行替代清晰的普通算法。
