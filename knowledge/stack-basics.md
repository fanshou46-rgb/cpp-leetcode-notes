# C++ 栈基础与经典用法

## 一、栈的特点

栈是后进先出（LIFO）的数据结构。

```cpp
#include <stack>
stack<int> st;
```

常用操作：

```cpp
st.push(x);   // 入栈
st.top();     // 查看栈顶
st.pop();     // 删除栈顶
st.empty();   // 是否为空
st.size();    // 元素数量
```

注意：`pop()` 不返回被删除的元素，需要先 `top()` 再 `pop()`。

## 二、表达式计算模板

逆波兰表达式中：

```text
数字 -> 入栈
运算符 -> 弹出两个数 -> 计算 -> 结果入栈
```

标准操作数顺序：

```cpp
int b = st.top(); st.pop();
int a = st.top(); st.pop();
```

之后计算：

```text
a 运算符 b
```

减法和除法尤其要注意顺序。

## 三、调用栈

函数调用类问题中，栈顶常表示“当前正在执行的函数”。

例如函数 A 调用 B：

```text
A 入栈
B 入栈
B 结束并出栈
继续执行 A
```

这类题常需要把栈与时间、状态等信息结合起来。

## 四、是否一定要真的使用 stack

题目描述里出现 Push/Pop，不代表实现时一定需要创建 `stack`。如果实际只需要记录操作序列或当前状态，可以省掉不必要的数据结构。

这是一种重要的优化意识：只维护真正影响答案的状态。
