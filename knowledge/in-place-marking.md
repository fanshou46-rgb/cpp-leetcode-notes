# C++ 数组原地标记

原地标记适用于数组值域与下标范围存在天然映射的题目，可以利用数组本身保存“是否出现”等状态，从而减少额外空间。

## 一、值到下标的映射

若题目保证：

```text
nums[i] ∈ [1,n]
```

而数组下标范围是：

```text
[0,n-1]
```

则可以建立：

```text
数字 x -> 下标 x-1
```

## 二、用正负号做状态标记

如果原数组元素全部为正数，可以把某位置改为负数表示对应数字已经出现：

```cpp
int x = abs(nums[i]);
nums[x - 1] = -abs(nums[x - 1]);
```

这里必须用 `abs(nums[i])`，因为当前元素可能已经在之前的标记过程中被改成负数。

## 三、寻找缺失数字

全部标记完成后，如果：

```cpp
nums[i] > 0
```

说明下标 `i` 从未被标记，因此对应数字：

```text
i + 1
```

没有在原数组中出现。

典型代码：

```cpp
vector<int> ans;
for (int i = 0; i < nums.size(); i++) {
    if (nums[i] > 0) {
        ans.push_back(i + 1);
    }
}
```

## 四、重复数字为什么不影响标记

使用：

```cpp
nums[x - 1] = -abs(nums[x - 1]);
```

即使数字 `x` 出现多次，同一个位置重复标记后仍然保持负数，因此不会把状态翻回正数。

## 五、复杂度

每个元素只处理常数次：

- 时间复杂度：`O(n)`
- 除返回答案外额外空间：`O(1)`

## 六、适用条件

看到下面特征时，可以考虑原地标记：

- 数组元素范围与数组长度相关，如 `[1,n]` 或 `[0,n-1]`。
- 可以把“值”映射为合法下标。
- 题目允许暂时修改输入数组。
- 需要降低额外空间。

典型应用：LeetCode 448「找到所有数组中消失的数字」、645「错误的集合」等。
