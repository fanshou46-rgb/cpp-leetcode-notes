## 一、84：柱状图中最大的矩形

### 1. 核心思路

对于每一根柱子，都把它看成当前矩形的最低高度。

如果柱子高度为 `heights[i]`，只要找到：

- 左边第一个严格比它矮的位置 `left`；
- 右边第一个严格比它矮的位置 `right`；

那么以当前柱子为高度能够形成的最大矩形宽度就是：

```cpp
width = right - left - 1;
```

面积为：

```cpp
area = heights[i] * width;
```

例如：

```text
heights = [2, 1, 5, 6, 2, 3]
```

对高度 `5` 而言：

```text
下标：  0  1  2  3  4  5
高度：  2  1  5  6  2  3
           ↑        ↑
         left     right
```

左边第一个更矮的位置是 `1`，右边第一个更矮的位置是 `4`，因此：

```cpp
width = 4 - 1 - 1 = 2;
area = 5 * 2 = 10;
```

暴力对每根柱子分别向左右寻找边界，最坏时间复杂度为 `O(n^2)`。

单调栈可以一次遍历完成，优化到 `O(n)`。

---

## 二、单调栈为什么能解决这题

从左到右遍历，栈中保存柱子的**下标**，并维护柱子高度递增。

当遇到一个更矮的柱子时，例如：

```text
5  6  2
      ↑ 当前柱子
```

当前高度 `2` 比栈顶高度 `6` 小，说明：

> 高度 `6` 再也不可能继续向右延伸，它的右边界已经确定。

因此可以把 `6` 对应的下标弹出并计算面积。

弹出以后：

- 当前下标 `i` 是右边第一个更矮的位置；
- 新的 `st.top()` 是左边界；
- 所以宽度为 `i - st.top() - 1`。

核心代码：

```cpp
while (st.top() != -1 && cur <= heights[st.top()]) {
    int h = heights[st.top()];
    st.pop();

    int width = i - st.top() - 1;
    ans = max(ans, h * width);
}
```

这里最重要的一点是：

> **弹栈的时刻，就是某根柱子的右边界被确定的时刻。**

## 三、完整推荐写法：`-1` 左哨兵 + 右侧虚拟 0

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        int ans = 0;

        stack<int> st;
        st.push(-1);  // 左边界哨兵

        for (int i = 0; i <= n; i++) {
            // i == n 时，相当于在最右边放一个高度为 0 的柱子
            int cur = (i == n ? 0 : heights[i]);

            while (st.top() != -1 &&
                   cur <= heights[st.top()]) {
                int h = heights[st.top()];
                st.pop();

                int width = i - st.top() - 1;
                ans = max(ans, h * width);
            }

            st.push(i);
        }

        return ans;
    }
};
```

## 四、为什么左边放 `-1` 哨兵

最开始自己写代码时，一个容易出现的问题是：

```cpp
st.pop();
int left = st.top();
```

如果栈中本来只有一个有效下标，`pop()` 之后栈会变空，再调用 `top()` 就会运行错误。

因此先放一个：

```cpp
st.push(-1);
```

这里的 `-1` 不代表真正的柱子，只表示数组左边界。

例如：

```text
下标：  -1   0   1   2 ...
        ↑
      左哨兵
```

当某根柱子一直能扩展到数组最左端时，宽度公式仍然成立：

```cpp
width = right - (-1) - 1;
```

同时在 `while` 中先判断：

```cpp
st.top() != -1
```

就可以保证哨兵不会被弹掉，栈也不会为空。

## 五、为什么右边还需要一个虚拟高度 0

如果柱子一直递增：

```text
[1, 2, 3, 4]
```

正常遍历时始终不会遇到更矮的柱子，所以栈中的柱子没有机会被弹出并计算面积。

因此遍历到 `i == n` 时人为令：

```cpp
cur = 0;
```

相当于：

```text
[1, 2, 3, 4, 0]
             ↑
          虚拟柱子
```

这样最后会强制把剩余柱子全部结算。

## 六、`<` 和 `<=` 的区别

这是这题里一个很重要的细节。

### 写成 `<`

```cpp
cur < heights[st.top()]
```

相同高度不会弹栈，因此栈中的高度是**非递减**的。

例如：

```text
[2, 2]
```

第二个 `2` 到来时，第一个 `2` 仍然保留。

最后遇到更矮的柱子时，再逐个计算。

### 写成 `<=`

```cpp
cur <= heights[st.top()]
```

相同高度也会弹栈，相当于让后一个相同高度的柱子“接管”前一个柱子的扩展范围。

这样栈中的高度能够保持**严格递增**。

使用 `-1` 下标哨兵后，`<=` 可以安全使用，因为：

```cpp
st.top() != -1
```

会先阻止左哨兵被弹出。

因此本题可以采用：

```cpp
while (st.top() != -1 && cur <= heights[st.top()])
```

需要注意：

> `<` 和 `<=` 都可以设计成正确算法，区别主要在于如何处理相同高度的柱子，而不是谁绝对正确、谁绝对错误。

## 七、为什么 `for + while` 仍然是 O(n)

虽然代码中有：

```cpp
for (...) {
    while (...) {
        ...
    }
}
```

但并不是 `O(n^2)`。

因为每个柱子的下标最多：

```text
入栈一次
出栈一次
```

因此整个过程中：

```text
push 总次数 <= n
pop 总次数  <= n
```

所以整体时间复杂度仍然是：

```text
O(n)
```

空间复杂度为：

```text
O(n)
```

这仍然是单调栈中典型的摊还分析。

## 八、和已经学过的单调栈题联系

单调栈常见信号仍然是：

```text
左边 / 右边
第一个 / 最近的
更大 / 更小
```

可以这样对比：

```text
1475 商品折扣后的最终价格
→ 找右边第一个 <= 当前值的位置

739 每日温度
→ 找右边第一个 > 当前值的位置

84 柱状图中最大的矩形
→ 找左右第一个 < 当前值的位置，并用边界计算区间面积
```

84 比前两题更进一步：

> 不只是寻找“第一个更大/更小”，还需要在弹栈时利用左右边界计算一个区间的贡献。

```cpp
st.push(-1);

for (int i = 0; i <= n; i++) {
    int cur = (i == n ? 0 : a[i]);

    while (st.top() != -1 && cur <= a[st.top()]) {
        int h = a[st.top()];
        st.pop();

        int width = i - st.top() - 1;

        // 使用 h 和 width 计算当前答案
    }

    st.push(i);
}
```

关键记忆：

```text
遇到更矮的柱子
→ 栈顶柱子的右边界确定
→ 弹栈
→ 弹栈后的新栈顶是左边界
→ width = right - left - 1
```

## 十、今日核心收获

1. 柱状图最大矩形可以转化为“为每根柱子寻找左右第一个更矮的位置”。
2. 单调栈的弹栈时刻，本质上是在确定某个元素的右边界。
3. 栈中存下标，比只存高度更有用，因为宽度计算需要下标。
4. `-1` 左哨兵可以统一处理数组左边界，并防止 `pop()` 后空栈访问 `top()`。
5. 末尾虚拟高度 `0` 可以强制结算递增栈中剩余的所有柱子。
6. `<` 与 `<=` 的区别主要是相同高度的处理方式；使用 `-1` 哨兵后可以自然使用 `<=` 保持严格递增栈。
7. `for + while` 不代表 `O(n^2)`，只要每个元素最多入栈、出栈一次，整体仍然是 `O(n)`。
8. 相比每日温度等题，84 进一步训练了“利用单调栈确定区间边界并计算贡献”的能力。
