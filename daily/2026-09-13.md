## 一、84：柱状图中最大的矩形

### 1. 核心思路

对于每一根柱子，都把它看成当前矩形的最低高度。

如果柱子高度为 `heights[i]`，只要找到：

- 左边第一个严格比它矮的位置 `left`；
- 右边第一个严格比它矮的位置 `right`；

那么以当前柱子为高度能够形成的最大矩形宽度就是：

```cpp
width = right - left - 1;
```

面积为：

```cpp
area = heights[i] * width;
```

例如：

```text
heights = [2, 1, 5, 6, 2, 3]
```

对高度 `5`：

```text
下标：  0  1  2  3  4  5
高度：  2  1  5  6  2  3
           ↑        ↑
         left     right
```

左边第一个更矮的位置是下标 `1`，右边第一个更矮的位置是下标 `4`，因此：

```cpp
width = 4 - 1 - 1 = 2;
area = 5 * 2 = 10;
```

暴力向左右寻找边界最坏需要 `O(n^2)`，单调栈可以优化到 `O(n)`。

## 二、左右各加一个高度 0 的哨兵

原数组：

```cpp
[2, 1, 5, 6, 2, 3]
```

处理成：

```cpp
[0, 2, 1, 5, 6, 2, 3, 0]
```

也就是：

```text
0  [2  1  5  6  2  3]  0
↑                       ↑
左哨兵                  右哨兵
```

这样可以统一处理所有边界情况。

### 左边的 0

左侧 `0` 永远不会被正常柱子弹出，所以栈始终有一个合法下标，可以直接使用：

```cpp
st.top()
```

不需要额外处理空栈。

### 右边的 0

如果柱子一直递增：

```text
[1, 2, 3, 4]
```

正常遍历时不会触发弹栈。

在最右侧添加 `0` 后：

```text
[0, 1, 2, 3, 4, 0]
                  ↑
```

最后这个 `0` 会把栈中剩余柱子全部弹出，使它们都能计算面积。

## 三、单调栈为什么能求左右边界

栈中保存的是**下标**，并让对应柱子高度保持单调不下降。

当当前柱子比栈顶柱子更矮时：

```text
5  6  2
      ↑ 当前柱子
```

因为：

```text
2 < 6
```

说明高度 `6` 已经不可能继续向右扩展，所以当前下标就是它右边第一个更矮的位置。

将 `6` 弹出后，新的栈顶就是它左边第一个更矮的位置。

因此弹栈时可以直接得到：

```cpp
right = i;
left = st.top();
width = right - left - 1;
```

这道题最关键的一句话：

> **遇到更矮的柱子时，栈顶柱子的右边界就确定了。**

## 四、完整代码

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();

        // 左右各加一个高度为 0 的哨兵
        vector<int> h(n + 2, 0);
        for (int i = 0; i < n; i++) {
            h[i + 1] = heights[i];
        }

        stack<int> st;
        st.push(0);  // 左侧高度 0 的哨兵下标

        int ans = 0;

        for (int i = 1; i < n + 2; i++) {
            // 当前柱子更矮：栈顶柱子的右边界确定
            while (h[i] < h[st.top()]) {
                int height = h[st.top()];
                st.pop();

                int width = i - st.top() - 1;
                ans = max(ans, height * width);
            }

            st.push(i);
        }

        return ans;
    }
};
```

## 五、为什么宽度是 `i - st.top() - 1`

弹出当前柱子后：

```cpp
int height = h[st.top()];
st.pop();
```

此时：

```text
st.top()              i
   ↓                  ↓
左边更矮 | 可用区域 | 右边更矮
```

左右两个边界本身都不能包含，所以：

```cpp
width = i - st.top() - 1;
```

例如高度 `5`：

```text
[0, 2, 1, 5, 6, 2, 3, 0]
       ↑        ↑
      left     right
```

对应：

```cpp
left = 2;
right = 5;
width = 5 - 2 - 1 = 2;
```

可以使用的正好是高度 `5、6` 两根柱子。

## 六、为什么 `while` 使用 `<`

代码中写：

```cpp
while (h[i] < h[st.top()])
```

因为相同高度的柱子并不会阻止矩形继续延伸。

例如：

```text
[2, 2]
```

两根高度相同的柱子可以共同形成：

```text
高度 = 2
宽度 = 2
面积 = 4
```

所以只有遇到**严格更矮**的柱子时，才说明栈顶柱子不能继续向右延伸，需要弹栈计算面积。

## 七、为什么是 O(n)

虽然代码中有：

```cpp
for (...) {
    while (...) {
        ...
    }
}
```

但每个柱子的下标最多只会：

```text
入栈一次
出栈一次
```

因此总的 `push` 和 `pop` 次数都是线性的。

所以：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

这是单调栈典型的摊还分析。

## 九、核心模板

```cpp
vector<int> h(n + 2, 0);
for (int i = 0; i < n; i++) {
    h[i + 1] = a[i];
}

stack<int> st;
st.push(0);

for (int i = 1; i < n + 2; i++) {
    while (h[i] < h[st.top()]) {
        int height = h[st.top()];
        st.pop();

        int width = i - st.top() - 1;
        // 用 height 和 width 计算答案
    }

    st.push(i);
}
```

记忆顺序：

```text
左右各加 0
→ 维护单调递增栈
→ 遇到更矮柱子
→ 弹出栈顶
→ 当前 i 是右边界
→ 新栈顶是左边界
→ width = right - left - 1
```

## 十、核心收获

1. 把每根柱子看成矩形的最低高度。
2. 最大范围由左右第一个严格更矮的柱子决定。
3. 左右各加一个高度 `0` 的哨兵，可以统一处理左右边界。
4. 单调栈中存下标，因为计算矩形宽度需要位置。
5. 弹栈时，当前下标是右边界，新的栈顶是左边界。
6. 宽度公式是 `right - left - 1`。
7. 每个下标最多入栈、出栈一次，所以整体是 `O(n)`。
