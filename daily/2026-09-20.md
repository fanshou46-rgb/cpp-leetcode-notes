## 一、1705. 吃苹果的最大数目

核心贪心：

> 每天优先吃“最早腐烂”的那批苹果。

每批苹果保存：

```cpp
{腐烂日期, 剩余数量}
```

使用小根堆：

```cpp
priority_queue<
    pair<int,int>,
    vector<pair<int,int>>,
    greater<pair<int,int>>
> q;
```

第 `i` 天新苹果的腐烂日期：

```cpp
i + days[i]
```

每天顺序：

```text
新苹果入堆
→ 删除已经腐烂的批次
→ 吃堆顶的一颗
→ 还有剩余则放回堆
```

数组结束后，堆中可能仍有可吃苹果，因此循环条件：

```cpp
while (i < apples.size() || !q.empty())
```

## 二、622. 设计循环队列：先理解原理

普通数组队列如果只让下标一直增加，前面已经空出的空间无法重新使用。

循环队列的关键：

```cpp
index = (index + 1) % capacity;
```

例如容量为 3：

```text
0 → 1 → 2 → 0 → 1 → 2 ...
```

因此数组首尾在逻辑上连接成一个环。

循环队列仍然遵循 FIFO：

```text
队尾入队
队首出队
```
