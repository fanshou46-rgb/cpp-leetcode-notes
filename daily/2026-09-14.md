# 2026-09-14 学习记录

## 今日主题：队列 Queue

队列的核心特点是：

```text
先进先出 FIFO（First In First Out）
```

可以理解为现实中的排队：先进入队列的人先被处理。

常用操作：

```cpp
queue<int> q;

q.push(x);   // 队尾加入元素
q.front();   // 查看队头
q.back();    // 查看队尾
q.pop();     // 删除队头，不返回元素
q.empty();   // 是否为空
q.size();    // 当前元素个数
```

如果既想取得队头又要删除：

```cpp
int x = q.front();
q.pop();
```

普通 `queue` 的 `push`、`pop`、`front`、`back`、`empty`、`size` 都可以看作 `O(1)`。

队列最常见的应用包括：

- 按顺序模拟排队过程；
- BFS 广度优先搜索；
- 二叉树层序遍历；
- “处理完还没结束，就重新排到队尾”的循环模拟。

## 一、1700. 无法吃午餐的学生数量

### 思路

学生用 `queue` 模拟排队，同时用 `cnt[2]` 统计当前剩余学生中喜欢两种三明治的人数。

过程：

```text
当前学生喜欢当前三明治
→ 学生出队，三明治下标后移

当前学生不喜欢
→ 队头移动到队尾

当前三明治已经没人喜欢
→ 后续无法继续，直接结束
```

只记录简洁版：

```cpp
class Solution {
public:
    int countStudents(vector<int>& students, vector<int>& sandwiches) {
        queue<int> q;
        int cnt[2] = {0};

        for (int x : students) {
            q.push(x);
            cnt[x]++;
        }

        int i = 0;

        while (!q.empty()) {
            if (cnt[sandwiches[i]] == 0)
                break;

            if (q.front() == sandwiches[i]) {
                cnt[q.front()]--;
                q.pop();
                i++;
            } else {
                q.push(q.front());
                q.pop();
            }
        }

        return q.size();
    }
};
```

队头移动到队尾的常用写法：

```cpp
q.push(q.front());
q.pop();
```

关键终止条件：

```cpp
cnt[sandwiches[i]] == 0
```

这说明当前栈顶三明治已经没有任何剩余学生需要，队列继续旋转也不会产生结果。

## 二、2073. 买票需要的时间

### 思路

队列中不要存票数，而是存人的**下标**。

这样可以通过：

```cpp
tickets[person]
```

直接修改这个人的剩余票数，同时可以判断当前人是不是目标位置 `k`。

每轮：

```text
队头出队
→ 买一张票
→ time++
→ 如果还没买完，再回到队尾
```

当 `tickets[k] == 0` 时，目标人物已经买完，结束模拟。

```cpp
class Solution {
public:
    int timeRequiredToBuy(vector<int>& tickets, int k) {
        queue<int> q;

        for (int i = 0; i < tickets.size(); i++) {
            q.push(i);
        }

        int time = 0;

        while (tickets[k] > 0) {
            int person = q.front();
            q.pop();

            tickets[person]--;
            time++;

            if (tickets[person] > 0)
                q.push(person);
        }

        return time;
    }
};
```

这里体现了一个常见队列模板：

```cpp
int x = q.front();
q.pop();

// 处理 x

if (还需要继续处理)
    q.push(x);
```

复杂度：

```text
时间：O(S)
```

其中 `S` 是第 `k` 个人买完前实际卖出的票数，最坏可到 `O(sum(tickets))`。

```text
空间：O(n)
```

因为队列最多保存 `n` 个人。

## 三、232. 用栈实现队列

### 核心思想

两个栈分工：

```text
in  ：负责入队
out ：负责出队和查看队头
```

栈是后进先出，队列是先进先出。

元素先进入 `in`，再从 `in` 全部倒入 `out`，顺序会被反转一次，因此 `out.top()` 正好变成最早进入的元素。

最关键的规则：

> 只有当 `out` 为空时，才把 `in` 中的元素全部倒过去。

```cpp
class MyQueue {
public:
    stack<int> in;
    stack<int> out;

    MyQueue() {
    }

    void push(int x) {
        in.push(x);
    }

    int pop() {
        if (out.empty()) {
            while (!in.empty()) {
                out.push(in.top());
                in.pop();
            }
        }

        int x = out.top();
        out.pop();
        return x;
    }

    int peek() {
        if (out.empty()) {
            while (!in.empty()) {
                out.push(in.top());
                in.pop();
            }
        }

        return out.top();
    }

    bool empty() {
        return in.empty() && out.empty();
    }
};
```

可以记成：

```text
in 管进
out 管出
out 没货了，才从 in 补货
```

### 为什么 `pop()` 要返回值

这里的 `pop()` 是题目规定的接口：

```cpp
int pop()
```

要求“删除并返回队头元素”。

但 C++ 自带 `stack::pop()` 只负责删除，不返回值，所以实现时需要：

```cpp
int x = out.top();
out.pop();
return x;
```

### 复杂度

某一次 `pop()` 或 `peek()` 在搬运元素时可能达到 `O(n)`，但每个元素只会：

```text
进入 in 一次
从 in 转移到 out 一次
从 out 删除一次
```

因此从整体上看：

```text
push：O(1)
pop：摊还 O(1)
peek：摊还 O(1)
empty：O(1)
空间：O(n)
```

## 今日核心收获

1. `queue` 是先进先出，适合处理“谁先来谁先处理”的问题。
2. 队列模拟中，经常应该存对象的**下标**而不是只存对象当前的值，这样更方便修改原数组状态。
3. “出队 → 处理 → 未完成则重新入队”是非常常见的队列模拟模板。
4. 队列旋转时必须考虑什么时候无法继续，不能只让队列无限循环。
5. 两个栈可以实现一个队列：`in` 负责进入，`out` 负责出去。
6. `out` 只有为空时才从 `in` 补充元素，这是保证顺序正确和摊还 `O(1)` 的关键。
7. STL 的 `pop()` 通常只删除元素；题目自定义函数是否返回值，要看函数接口要求。
