## 今日学习：队列

### 1700. 无法吃午餐的学生数量

这题用 `queue` 模拟学生队列，同时用 `cnt[2]` 记录剩余学生中喜欢两种三明治的人数。

核心判断：

- 当前学生喜欢栈顶三明治：学生出队，三明治下标后移；
- 当前学生不喜欢：把队头学生移到队尾；
- 如果当前三明治已经没有任何学生喜欢，直接结束。

只保留这一版简洁写法：

```cpp
class Solution {
public:
    int countStudents(vector<int>& students, vector<int>& sandwiches) {
        queue<int> q;
        int cnt[2] = {0};

        for (int x : students) {
            q.push(x);
            cnt[x]++;
        }

        int i = 0;

        while (!q.empty()) {
            if (cnt[sandwiches[i]] == 0)
                break;

            if (q.front() == sandwiches[i]) {
                cnt[q.front()]--;
                q.pop();
                i++;
            } else {
                q.push(q.front());
                q.pop();
            }
        }

        return q.size();
    }
};
```

需要记住的队列操作：

```cpp
q.push(x);   // 队尾加入
q.front();   // 查看队头
q.pop();     // 删除队头
q.empty();   // 判断是否为空
q.size();    // 队列长度
```

把队头移动到队尾：

```cpp
q.push(q.front());
q.pop();
```

这题的关键不是让队列一直轮转，而是判断：

```cpp
cnt[sandwiches[i]] == 0
```

一旦当前三明治已经没人喜欢，后面的过程就无法继续。
