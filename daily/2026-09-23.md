## 一、链表合并与 head / tail
创建链表时常同时维护：
~~~cpp
ListNode* head = nullptr;
ListNode* tail = nullptr;
~~~
第一次插入：
~~~cpp
if (head == nullptr) {
    head = tail = node;
} else {
    tail->next = node;
    tail = node;
}
~~~
核心：head 指向第一个节点，tail 指向最后一个节点；尾插后必须让 tail 移到新节点。

两个有序链表可以用两个指针比较当前节点，并把较小节点接到结果尾部。最后把剩余链表整体接上。

## 二、nullptr 与 p->next
p->next 等价于 (*p).next，但 p 必须指向有效对象。如果 p == nullptr，就不能访问 p->next。
常见安全遍历：
~~~cpp
while (p != nullptr) {
    // 可以安全访问 p->val / p->next
    p = p->next;
}
~~~

## 三、new(...) 与 new{...}
new T(...) 使用圆括号直接初始化；new T{...} 使用花括号列表初始化。
对于简单结构：
~~~cpp
struct Node {
    int val;
    Node* next;
};
Node* p = new Node{x, nullptr};
~~~
这里按成员顺序初始化 val 和 next。

## 四、输入以 -1 结束
有些链表题规定 -1 是输入结束标志，它不是 EOF，也不应该作为正常节点加入链表。
~~~cpp
int x;
while (cin >> x && x != -1) {
    // 创建节点并尾插
}
~~~

## 五、约瑟夫环
循环单链表中最后一个节点的 next 指向第一个节点，因此可以模拟报数与删除。
删除本质：
~~~cpp
prev->next = cur->next;
delete cur;
~~~
删除后从下一个节点继续计数。如果只求幸存者，也可以使用约瑟夫递推公式；需要过程模拟时，循环链表更直观。

## 六、随机指针链表深拷贝
节点除了 next 外，还有可能指向任意节点的 random。
~~~cpp
struct Node {
    int val;
    Node* next;
    Node* random;
};
~~~
核心使用：
~~~cpp
unordered_map<Node*, Node*> mp;
~~~
保存 原节点地址 -> 新节点地址。
第一遍创建所有新节点：
~~~cpp
for (Node* cur = head; cur != nullptr; cur = cur->next) {
    mp[cur] = new Node(cur->val);
}
~~~
第二遍连接：
~~~cpp
for (Node* cur = head; cur != nullptr; cur = cur->next) {
    mp[cur]->next = mp[cur->next];
    mp[cur]->random = mp[cur->random];
}
~~~
这样新链表的 next 和 random 都指向新节点，不会混入原链表。

## 今日核心收获
1. head 管第一个节点，tail 管最后一个节点，尾插可以做到 O(1)。
2. 有序链表合并的核心是比较两个当前节点，并把较小节点接到结果尾部。
3. p->next 等价于 (*p).next，但 p 必须指向有效对象。
4. nullptr 表示空指针，不是一个普通节点。
5. new T(...) 和 new T{...} 都可以动态创建对象，但初始化规则不同。
6. 约瑟夫环可以用循环链表模拟删除。
7. 随机指针链表深拷贝可以用 unordered_map<Node*, Node*> 建立原节点到新节点的映射。
