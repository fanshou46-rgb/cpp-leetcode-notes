## 一、C++ 与 vector

LeetCode 已经准备好主函数和测试环境，只需要实现 `class Solution` 中指定的成员函数。

`vector<int>` 是整数动态数组。`nums.size()` 获取长度，`nums[i]` 访问下标为 i 的元素，`vector<int> ans(n)` 创建 n 个初始化为 0 的元素。

数组截取使用左闭右开区间：

`vector<int> sub(nums.begin()+l, nums.begin()+r);`

该写法截取下标 l 到 r-1 的元素。若要包含下标 r，右边界应写成 r+1。

引用传参 `vector<int>& nums` 不会复制整个数组，但通过引用修改元素会影响原数组。`const vector<int>& nums` 可以避免复制，同时禁止通过该引用修改数组。

## 二、数组串联与交替排列

数组串联的核心是把每个元素放到两个位置：

`ans[i] = nums[i];`

`ans[i+n] = nums[i];`

重新排列数组的核心是交替放置：

`ans[2*i] = nums[i];`

`ans[2*i+1] = nums[i+n];`

两道题都只需要一次线性遍历。能够直接从原数组读取时，不必额外截取左右子数组。

## 三、最大连续 1 的个数

使用 cnt 记录当前连续长度，best 记录历史最大长度。

遇到 1：cnt 增加 1，并立即更新 `best = max(best, cnt)`。

遇到 0：将 cnt 清零。

最初的错误是只在遇到 0 时更新最大值，导致数组末尾的连续 1 被遗漏；直接赋值也可能让较短的连续段覆盖历史最大值。

时间复杂度 O(n)，辅助空间 O(1)。

## 四、统计范围内的逗号

题目统计的是 1 到 n 所有整数的逗号总数，而不是 n 自身的逗号个数。

按 1000、1000000、1000000000 等门槛分别统计。对于不超过 n 的门槛 p，该层贡献 `n-p+1` 个逗号。

错误复盘：使用 `while(n<1000)` 且不断执行整数除法时，n=998 会变成 0，之后循环条件永远成立，造成死循环。

今后写 while 循环，要检查循环变量是否一定会使循环终止，并特别测试 0、1、边界值。

## 五、错误的集合：四种解法

### 1. 计数数组

使用 `cnt[nums[i]]++` 统计每个数字的出现次数。

出现 2 次的是重复值，出现 0 次的是丢失值。返回顺序为 `[重复值, 丢失值]`。

时间 O(n)，辅助空间 O(n)。

### 2. 数学求和

设重复值为 d，丢失值为 m。

A = 实际总和 - 正确总和 = d-m

B = 实际平方和 - 正确平方和 = d²-m² = (d-m)(d+m)

因此：

d = (A+B/A)/2

m = d-A

使用 long long 避免平方和溢出。时间 O(n)，辅助空间 O(1)。

### 3. 原地标记

数字 x 对应下标 x-1。第一次遇到 x，把该位置变为负数；再次遇到时，如果已经为负，说明 x 重复。

最后仍为正数的位置对应丢失值。由于数组元素可能已经被修改，读取原始数字时需要使用 abs。

这种方法可恢复原数组，辅助空间 O(1)。

### 4. 异或分组

把实际数组与正确集合 1 到 n 的所有数字异或，正常数字成对抵消，得到：

X = d ^ m

使用 `lowbit = X & -X` 找到 d 和 m 不同的一个二进制位。

按照这一位把两个集合中的所有数字分组。相同的正常数字进入同一组并抵消，而 d 和 m 进入不同组，最终两组分别剩下两个目标数字。

最后扫描原数组，判断哪个是重复值。

时间 O(n)，辅助空间 O(1)，不修改原数组。

## 六、位运算知识

* 按位与 `&`：两个位都为 1 才为 1。
* 按位或 `|`：至少一个位为 1 就为 1。
* 按位异或 `^`：相同为 0，不同为 1。
* 按位取反 `~`：逐位交换 0 和 1。
* 左移 `<<`：二进制向左移动。
* 右移 `>>`：二进制向右移动。

异或的重要性质：

`a ^ a = 0`

`a ^ 0 = a`

异或满足交换律和结合律，因此适合成对抵消。

常用技巧：

* `x & 1`：判断奇偶。
* `x & -x`：提取最低位的 1。
* `x & (x-1)`：清除最低位的 1。
* `x & (1u << k)`：检查第 k 位。
* `x |= (1u << k)`：设置第 k 位。
* `x &= ~(1u << k)`：清除第 k 位。
* `x ^= (1u << k)`：翻转第 k 位。

## 七、Lowbit 的补码原理

在固定宽度的二进制补码表示中，负数等于对应正数按位取反再加 1。

假设：

x = A 1 000...000

其中中间的 1 是最低位的 1。

取反后：

~x = ~A 0 111...111

加 1 后，末尾连续的 1 全部变为 0，进位停在原来最低位的 1 上：

-x = ~A 1 000...000

再按位与，高位 A 与 ~A 抵消，右侧全是 0，最终只留下最低位的那个 1。

例如：

12 = 00001100

-12 = 11110100

按位与得到 00000100，即 4。

## 八、复杂度与性能认识

O(n) 表示算法的增长数量级，不代表所有线性算法的实际运行时间都相同。

计数数组和位运算都是 O(n)，但位运算可能需要更多次遍历。位运算的主要优势是辅助空间从 O(n) 降到 O(1)，不保证每次提交的毫秒数一定更低。

LeetCode 的单次运行时间和击败百分比会受到测试环境波动影响，应优先关注正确性、复杂度和代码可读性。
