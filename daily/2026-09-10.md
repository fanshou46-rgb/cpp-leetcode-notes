## 一、二叉树递归：2265

每个节点都需要知道其整棵子树的节点值之和与节点数量，因此适合使用后序遍历：先处理左右子树，再处理当前节点。

递归函数返回 `pair<int,int>`：

- `first`：子树节点值之和。
- `second`：子树节点数。

递推关系：

```cpp
sum = leftSum + rightSum + root->val;
count = leftCount + rightCount + 1;
```

判断：

```cpp
if (sum / count == root->val) ans++;
```

结构化绑定可以让返回值更清晰：

```cpp
auto [leftSum, leftCount] = dfs(root->left);
auto [rightSum, rightCount] = dfs(root->right);
```

核心认识：父节点依赖左右子树的信息时，常采用“递归返回子树信息”的后序遍历模式。

## 二、计数与前缀和：1365

第一版可以对每个元素统计比它小的数，最坏时间复杂度为 `O(n^2)`。

若先统计每个值出现的次数，再做前缀和：

```cpp
cnt[i] += cnt[i - 1];
```

此时 `cnt[i]` 表示小于等于 `i` 的元素个数，因此严格小于 `x` 的数量为：

```cpp
cnt[x - 1]
```

当题目值域很小时，固定大小计数数组通常比 `unordered_map` 更直接。

## 三、原地标记：448

题目保证 `nums[i]` 位于 `[1,n]`，而数组下标位于 `[0,n-1]`，因此可建立映射：

```text
数字 x -> 下标 x-1
```

遍历时：

```cpp
int x = abs(nums[i]);
nums[x - 1] = -abs(nums[x - 1]);
```

负号表示数字 `x` 已出现。最后仍为正数的位置 `i` 对应缺失数字 `i+1`。

重要点：读取当前元素时使用 `abs`，因为数组中的数可能已经被前面的标记操作改成负数。

该方法时间复杂度 `O(n)`，除返回数组外额外空间 `O(1)`。

## 四、栈基础与 1441

常用操作：

```cpp
stack<int> st;
st.push(x);
st.top();
st.pop();
st.empty();
st.size();
```

`pop()` 只删除栈顶，不返回元素。若需要栈顶值，应先 `top()` 再 `pop()`。

1441 中虽然题目描述了栈操作，但并不一定需要真正维护一个 `stack`。刚压入的元素就是当前整数流中的数字，因此只需记录操作序列并维护 `target` 的下标即可。

核心认识：题目出现某种数据结构，不代表实现时必须真的创建该数据结构；只保留影响答案的状态可以让代码更简洁。

## 五、逆波兰表达式：150

经典栈模板：

```text
遇到数字 -> 入栈
遇到运算符 -> 弹出两个数 -> 计算 -> 结果重新入栈
```

数字字符串使用：

```cpp
stoi(x)
```

最重要的是操作数顺序：

```cpp
int b = st.top(); st.pop();
int a = st.top(); st.pop();
```

之后始终计算：

```text
a 运算符 b
```

对于减法和除法尤其不能写反。

## 六、函数独占时间：636

调用栈的栈顶表示当前正在占用 CPU 的函数。使用 `pre` 表示上一段尚未结算时间的起点。

日志格式如：

```text
0:start:3
1:end:5
```

使用 `find + substr + stoi` 解析：

```cpp
int p1 = x.find(':');
int p2 = x.find(':', p1 + 1);
int id = stoi(x.substr(0, p1));
string type = x.substr(p1 + 1, p2 - p1 - 1);
int time = stoi(x.substr(p2 + 1));
```

遇到 `start`：

```cpp
if (!st.empty()) ans[st.top()] += time - pre;
st.push(id);
pre = time;
```

遇到 `end`：

```cpp
ans[st.top()] += time - pre + 1;
st.pop();
pre = time + 1;
```

`end` 时间戳本身属于正在结束的函数，因此要 `+1`；下一段从 `time+1` 开始。

## 八、今日核心收获

1. 二叉树中“先得到左右子树信息，再计算当前节点”是典型后序递归模式。
2. `pair` 可以一次返回两个值，结构化绑定能提高可读性。
3. 前缀和不仅用于原数组求和，也可以对“频次数组”做累计。
4. 当值域 `[1,n]` 与下标 `[0,n-1]` 可映射时，可以利用数组自身做原地标记。
5. 栈适合处理后进先出、表达式计算和调用关系。
6. `find + substr + stoi` 是解析简单格式化字符串的实用组合。
7. 不以 LeetCode 单次运行时间或内存排名判断算法优劣，优先关注复杂度、状态是否必要和代码可读性。
