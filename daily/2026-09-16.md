## 二、520. 检测大写字母

合法情况只有三种：

```text
1. 全部大写
2. 全部小写
3. 只有首字母大写
```

可以统计大写字母数量：

```cpp
class Solution {
public:
    bool detectCapitalUse(string word) {
        int cnt = 0;

        for (char c : word) {
            if (isupper(c))
                cnt++;
        }

        return cnt == 0 ||
               cnt == word.size() ||
               (cnt == 1 && isupper(word[0]));
    }
};
```

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 今日核心收获

1. 堆题不一定正向模拟，逆向恢复有时更简单。
2. `isupper / islower / toupper / tolower` 是字符串题常用字符函数。
3. 字符串规则题先把合法情况分类，再写判断条件，通常比逐字符维护复杂状态更清晰。
