## 一、链表常见操作

链表的核心始终是：

> 明确当前指针指向谁，再决定 next 应该改成谁。

### 反转链表

使用三个指针：

~~~cpp
ListNode* prev = nullptr;
ListNode* cur = head;

while (cur != nullptr) {
    ListNode* next = cur->next;
    cur->next = prev;
    prev = cur;
    cur = next;
}

return prev;
~~~

必须先保存 `next`，否则修改 `cur->next` 后会失去后半段链表。

### 快慢指针

找中点：

~~~cpp
ListNode* slow = head;
ListNode* fast = head;

while (fast != nullptr && fast->next != nullptr) {
    slow = slow->next;
    fast = fast->next->next;
}
~~~

判断是否有环也是同一思想：slow 每次走一步，fast 每次走两步；如果有环，两者最终会相遇。

## 二、83 删除排序链表中的重复元素

因为链表已经有序，重复元素一定相邻。

核心判断：

~~~cpp
if (cur->val == cur->next->val) {
    cur->next = cur->next->next;
} else {
    cur = cur->next;
}
~~~

注意：

- 删除重复节点时，`cur` 不一定要移动，因为新的 `cur->next` 仍可能与 `cur` 重复。
- 必须保证 `cur != nullptr && cur->next != nullptr` 后再访问两个节点。

## 三、循环单链表判空

### 不带头结点

空链表没有任何节点：

~~~cpp
L == nullptr
~~~

### 带头结点

即使没有数据节点，头结点仍然存在，并且 next 指回自己：

~~~cpp
L->next == L
~~~

这里：

- `L`：头指针，保存头结点地址。
- `L->next`：头结点的 next 指针。
- `&L`：变量 L 自己在内存中的地址，和头结点地址不是一回事。

## 四、逻辑结构与存储结构

### 逻辑结构

描述数据之间“逻辑上是什么关系”：

- 集合
- 线性结构
- 树形结构
- 图状结构

### 存储结构

描述数据“实际怎么放在内存里”：

- 顺序存储：元素地址连续，例如数组、vector。
- 链式存储：节点地址不要求连续，通过指针连接，例如链表。

因此“线性表”是逻辑结构；它既可以用顺序表实现，也可以用链表实现。

## 五、哈希表与 unordered_map

`unordered_map<Key, Value>` 保存的是 key-value 映射。

~~~cpp
unordered_map<int, int> mp;

mp[10] = 3;
mp[20] = 7;
~~~

常用操作：

~~~cpp
mp.find(x)       // 查找 key
mp.count(x)      // 判断 key 是否存在
mp.erase(x)      // 删除 key
mp[x]            // 访问/修改 value
~~~

平均时间复杂度通常为 O(1)。

注意：`mp[x]` 在 x 不存在时会自动插入一个默认值，因此如果只是判断存在性，优先使用 `find` 或 `count`。

## 六、1 两数之和：为什么适合哈希表

目标：

~~~text
nums[i] + nums[j] = target
~~~

扫描到 `nums[i]` 时，只需要寻找：

~~~text
need = target - nums[i]
~~~

如果 need 已经在哈希表中，就找到了答案。

推荐顺序：

~~~cpp
unordered_map<int, int> mp;

for (int i = 0; i < nums.size(); i++) {
    int need = target - nums[i];

    if (mp.find(need) != mp.end()) {
        return {mp[need], i};
    }

    mp[nums[i]] = i;
}
~~~

必须“先查后存”，这样当前元素不会和自己配对。

复杂度：

- 时间：平均 O(n)
- 空间：O(n)

相比两层循环 O(n²)，哈希表用额外空间换取更快查找。

## 今日核心收获

1. 链表题的核心是 next 指针的连接关系。
2. 反转链表要先保存 next，再修改当前节点指向。
3. 快慢指针可用于找中点和判环。
4. 带头结点的循环单链表为空时满足 `L->next == L`。
5. 逻辑结构和存储结构不是同一个概念。
6. 哈希表适合“快速判断某个值是否已经出现”。
7. 两数之和的关键是把“找两个数”改写成“当前数 + 查找补数”。
