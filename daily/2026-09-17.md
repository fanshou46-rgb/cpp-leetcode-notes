## 一、831. 隐藏个人信息

### 邮箱

先判断是否包含 `@`。

邮箱格式要求：

```text
首字母 + ***** + @前最后一个字母 + @及后面的部分
```

并全部转成小写。

### 电话号码

先只保留数字：

```cpp
string num;

for (char c : s) {
    if (isdigit(c))
        num += c;
}
```

最后 10 位按：

```text
***-***-1234
```

处理。

如果有国家码，前面补：

```text
+*-     11 位
+**-    12 位
+***-   13 位
```

### 简洁实现

```cpp
class Solution {
public:
    string maskPII(string s) {
        int pos = s.find('@');

        if (pos != string::npos) {
            string ans;
            ans += tolower(s[0]);
            ans += "*****";
            ans += tolower(s[pos - 1]);

            for (int i = pos; i < s.size(); i++)
                ans += tolower(s[i]);

            return ans;
        }

        string num;

        for (char c : s) {
            if (isdigit(c))
                num += c;
        }

        string ans = "***-***-" + num.substr(num.size() - 4);
        int country = num.size() - 10;

        if (country > 0)
            ans = "+" + string(country, '*') + "-" + ans;

        return ans;
    }
};
```

## 二、459. 重复的子字符串

### 核心技巧

如果字符串 `s` 可以由某个子串重复若干次构成，那么：

```cpp
s + s
```

去掉第一个字符和最后一个字符后，仍然能够找到完整的 `s`。

例如：

```text
s = "abab"

s+s = "abababab"

去掉首尾：
"bababa"

其中仍然包含 "abab"
```

所以可以直接：

```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        string t = s + s;
        t = t.substr(1, t.size() - 2);

        return t.find(s) != string::npos;
    }
};
```

这里使用：

```cpp
find()
string::npos
```

即可，不额外记录其他字符串查找函数。
