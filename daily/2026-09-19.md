## 一、66. 加一

从数组末尾开始处理进位。

- 当前位小于 9：直接加 1 并返回。
- 当前位等于 9：变成 0，继续向前进位。
- 如果所有位都是 9，最后在开头补 1。

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        for (int i = digits.size() - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }

            digits[i] = 0;
        }

        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

时间复杂度：`O(n)`。

## 二、941. 有效的山脉数组

一个合法山脉必须：

```text
严格上升
→ 到达峰顶
→ 严格下降
```

峰顶不能在第一个或最后一个位置。

```cpp
class Solution {
public:
    bool validMountainArray(vector<int>& arr) {
        int n = arr.size();
        int i = 0;

        while (i + 1 < n && arr[i] < arr[i + 1])
            i++;

        if (i == 0 || i == n - 1)
            return false;

        while (i + 1 < n && arr[i] > arr[i + 1])
            i++;

        return i == n - 1;
    }
};
```

时间复杂度：`O(n)`，空间复杂度：`O(1)`。

## 三、316. 去除重复字母

核心目标：

- 每个字母只保留一次；
- 在满足条件的结果中，使字典序最小。

使用一个字符串当作单调栈，同时记录：

- `remain[c]`：字符后面还剩多少次；
- `used[c]`：字符是否已经在答案中。

如果当前字符比答案末尾字符更小，并且末尾字符后面还会再次出现，就可以把末尾字符弹掉，让当前字符提前。

## 四、482. 密钥格式化

因为第一组允许不足 `k` 个，而后面的组都必须恰好是 `k` 个，所以从右往左处理最自然。

过程：

```text
从右向左遍历
→ 跳过 '-'
→ 字母统一转大写
→ 每收集 k 个字符插入 '-'
→ 最后去掉多余 '-'
→ reverse
```

```cpp
class Solution {
public:
    string licenseKeyFormatting(string s, int k) {
        string ans;
        int cnt = 0;

        for (int i = s.size() - 1; i >= 0; i--) {
            if (s[i] == '-')
                continue;

            ans.push_back(toupper(s[i]));
            cnt++;

            if (cnt == k) {
                ans.push_back('-');
                cnt = 0;
            }
        }

        if (!ans.empty() && ans.back() == '-')
            ans.pop_back();

        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

边界情况：如果去掉 `-` 后没有有效字符，`ans` 为空，因此访问 `ans.back()` 前必须先判断：

```cpp
!ans.empty()
```

## 五、796. 旋转字符串

如果 `s` 是 `goal` 的某个旋转结果，那么在长度相同的前提下，`s` 一定是 `goal + goal` 的子串。

例如：

```text
goal = "abcde"
goal + goal = "abcdeabcde"

其中包含：
abcde
bcdea
cdeab
deabc
eabcd
```

代码：

```cpp
class Solution {
public:
    bool rotateString(string s, string goal) {
        return s.size() == goal.size() &&
               (goal + goal).find(s) != string::npos;
    }
};
```

这里长度判断不能省，否则长度不同的字符串也可能恰好成为子串。

## 六、686. 重复叠加字符串匹配

目标：寻找最少重复多少次 `a`，使得 `b` 成为重复字符串的子串。

先不断追加原始 `a`，直到当前字符串长度至少达到 `b`：

```cpp
while (s.size() < b.size()) {
    s += a;
    cnt++;
}
```

达到长度后先检查一次；如果没找到，再额外追加一次 `a`。

原因：如果答案存在，长度刚刚覆盖 `b` 后仍未匹配，唯一还需要考虑的是 `b` 横跨当前重复字符串的末尾和下一份 `a` 的开头，因此最多再补一份。

```cpp
class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        string s = a;
        int cnt = 1;

        while (s.size() < b.size()) {
            s += a;
            cnt++;
        }

        if (s.find(b) != string::npos)
            return cnt;

        s += a;

        if (s.find(b) != string::npos)
            return cnt + 1;

        return -1;
    }
};
```

注意不要写成：

```cpp
a += a;
```

如果本意是“每次多重复一份原字符串”，该写法会让字符串长度每次翻倍，重复次数与循环变量对不上。

## 七、KMP 字符串匹配入门

今天进一步学习了 KMP。

核心思想：

> 失配后不让文本串指针回退，而是利用模式串中已经匹配部分的前后缀结构，让模式串指针跳转。

两个关键指针：

```text
i：文本串位置
j：模式串位置
```

当字符相等：

```cpp
i++;
j++;
```

当字符失配且 `j > 0`：

```cpp
j = lps[j - 1];
```

此时 `i` 不回退。

### LPS

`lps[i]` 表示模式串 `p[0...i]` 中“最长相等真前缀和后缀”的长度。

例如：

```text
p   = a b a b a c a
lps = 0 0 1 2 3 0 1
```

构造 LPS 时，若当前位置失配但当前前后缀长度不为 0：

```cpp
len = lps[len - 1];
```

不是直接清零，因为还可能存在更短的可用前后缀。

## 今日核心收获

1. 数组进位题常从最低位向最高位处理。
2. “先严格上升再严格下降”可以用两个连续 while 阶段完成。
3. 单调栈不仅能找边界，也能配合贪心构造字典序最小结果。
4. “第一组可短、后续组固定长度”的字符串分组题，常适合从右往左处理。
5. `front()`、`back()` 可以直接访问字符串首尾字符，但空串不能直接调用。
6. `find()` 未找到时返回 `string::npos`，判断时优先写 `!= string::npos`，不要依赖 `-1`。
7. 旋转字符串可利用 `goal + goal` 的子串性质判断。
8. 重复拼接匹配题通常只需重复到长度覆盖目标，再额外检查一份。
9. KMP 的核心是“文本指针不回退，模式指针按 LPS 跳转”。
