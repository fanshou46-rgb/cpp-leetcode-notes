## 一、66. 加一

从数组末尾开始处理进位。

- 当前位小于 9：直接加 1 并返回。
- 当前位等于 9：变成 0，继续向前进位。
- 如果所有位都是 9，最后在开头补 1。

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        for (int i = digits.size() - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }

            digits[i] = 0;
        }

        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

时间复杂度：`O(n)`。

## 二、941. 有效的山脉数组

一个合法山脉必须：

```text
严格上升
→ 到达峰顶
→ 严格下降
```

峰顶不能在第一个或最后一个位置。

```cpp
class Solution {
public:
    bool validMountainArray(vector<int>& arr) {
        int n = arr.size();
        int i = 0;

        while (i + 1 < n && arr[i] < arr[i + 1])
            i++;

        if (i == 0 || i == n - 1)
            return false;

        while (i + 1 < n && arr[i] > arr[i + 1])
            i++;

        return i == n - 1;
    }
};
```

时间复杂度：`O(n)`，空间复杂度：`O(1)`。

## 三、316. 去除重复字母

核心目标：

- 每个字母只保留一次；
- 在满足条件的结果中，使字典序最小。

使用一个字符串当作单调栈，同时记录：

- `remain[c]`：字符后面还剩多少次；
- `used[c]`：字符是否已经在答案中。

如果当前字符比答案末尾字符更小，并且末尾字符后面还会再次出现，就可以把末尾字符弹掉，让当前字符提前。

## 四、482. 密钥格式化

因为第一组允许不足 `k` 个，而后面的组都必须恰好是 `k` 个，所以从右往左处理最自然。

过程：

```text
从右向左遍历
→ 跳过 '-'
→ 字母统一转大写
→ 每收集 k 个字符插入 '-'
→ 最后去掉多余 '-'
→ reverse
```

```cpp
class Solution {
public:
    string licenseKeyFormatting(string s, int k) {
        string ans;
        int cnt = 0;

        for (int i = s.size() - 1; i >= 0; i--) {
            if (s[i] == '-')
                continue;

            ans.push_back(toupper(s[i]));
            cnt++;

            if (cnt == k) {
                ans.push_back('-');
                cnt = 0;
            }
        }

        if (!ans.empty() && ans.back() == '-')
            ans.pop_back();

        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

边界情况：如果去掉 `-` 后没有有效字符，`ans` 为空，因此访问 `ans.back()` 前必须先判断：

```cpp
!ans.empty()
```

## 今日核心收获

1. 数组进位题常从最低位向最高位处理。
2. “先严格上升再严格下降”可以用两个连续 while 阶段完成。
3. 单调栈不仅能找边界，也能配合贪心构造字典序最小结果。
4. “第一组可短、后续组固定长度”的字符串分组题，常适合从右往左处理。
