## 一、1732 找到最高海拔
从 0 出发，当前海拔等于前一个海拔加上 gain[i]。只需要最高值，不需要完整前缀数组。
~~~cpp
int cur = 0;
int ans = 0;
for (int x : gain) {
    cur += x;
    ans = max(ans, cur);
}
return ans;
~~~
时间 O(n)，空间 O(1)。起点 0 也必须参与最大值比较。

## 二、1590 使数组和能被 P 整除
设整个数组和的余数为 need。删除区间的和也必须模 p 等于 need。
用前缀和取模。若当前余数为 r，需要寻找前面的余数 q，使：
~~~text
(r - q + p) % p = need
~~~
因此 q = (r - need + p) % p。
因为目标是最短删除区间，哈希表通常保存最近一次出现的位置。
总和余数为 0 时直接返回 0。

## 三、1664 生成平衡数组的方案数
删除 nums[i] 后，右侧所有元素都会向左移动一位，因此右侧元素的奇偶下标全部翻转。
设删除前左侧和右侧的偶奇下标元素和分别为：
leftEven, leftOdd, rightEven, rightOdd。
删除后：
~~~text
新偶数位和 = leftEven + rightOdd
新奇数位和 = leftOdd + rightEven
~~~
如果两者相等，则该删除位置形成一个平衡数组。一次遍历维护左右奇偶和即可做到 O(n)。

## 四、1019 链表中的下一个更大节点
目标是找到每个节点右侧第一个严格更大的节点。
当前节点负责解决前面还没有答案的较小节点，因此使用单调递减栈。
~~~cpp
stack<pair<int, int>> st;
while (!st.empty() && cur->val > st.top().first) {
    int index = st.top().second;
    st.pop();
    ans[index] = cur->val;
}
st.push({cur->val, index});
~~~
栈保存 节点值 + 节点下标。每个节点最多入栈一次、出栈一次，因此时间 O(n)，空间 O(n)。

## 五、523 连续的子数组和
如果两个前缀和对 k 的余数相同，那么它们之间的连续子数组和一定是 k 的倍数：
~~~text
prefix[i] % k == prefix[j] % k
        =>
(prefix[i] - prefix[j]) % k == 0
~~~
用 unordered_map 保存每个余数第一次出现的位置，并初始化 mp[0] = -1。
再次遇到相同余数时，检查 i - mp[r] >= 2。
只保存第一次出现的位置，是因为第一次位置最早，可以形成最长候选区间；长度不足时也不能覆盖掉这个位置。

## 六、为什么这里不能直接用 vector 当余数表
前缀和数组可以用 vector，因为下标是原数组位置 0 到 n-1。
但如果写 vector<int> an(n + 2)，再访问 an[sum % k]，此时下标是余数，范围是 0 到 k-1，而 k 可能远大于 n。
理论上开 vector<int> an(k) 也可能需要巨大内存。
所以：
~~~text
key 值域小、连续 -> vector
key 值域大、稀疏 -> unordered_map
~~~
判断容器时要看 key 的值域，而不是只看元素数量。

## 今日核心收获
1. 前缀和不一定需要完整数组，只需要累计量时可以滚动维护。
2. 前缀和取模能把区间整除问题转化成余数之间的关系。
3. 1590 是寻找目标余数，523 是寻找相同余数。
4. 1664 的关键是删除后右侧奇偶下标整体翻转。
5. 1019 与每日温度属于同一类单调栈模型。
6. vector 与 unordered_map 的选择取决于 key 的值域。
