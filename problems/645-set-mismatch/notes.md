# 645. 错误的集合

## 题目信息

* 题目：LeetCode 645
* 难度：简单
* 分类：数组、计数、数学、位运算
* 状态：已通过
* 返回格式：`[重复值, 丢失值]`

## 一、题目理解

原本的集合包含 1 到 n 的每个整数，且每个数字恰好出现一次。由于数据错误，一个数字重复，另一个数字丢失。需要同时找出这两个数字。

例如：

```text
输入：[1, 2, 2, 4]
输出：[2, 3]
```

数字 2 出现了两次，数字 3 没有出现。

## 二、第一版思路与错误

最初使用双重循环比较 `nums[i]` 和 `nums[j]`，当两个元素相等时，使用 min 和 max 记录答案。

问题在于：两个相等的数字都只能得到重复值，无法推断丢失值。

例如两个元素都是 2 时：

```cpp
min(2, 2) == 2
max(2, 2) == 2
```

只能得到 `[2,2]`，而不是 `[2,3]`。

**复盘：** 找到重复值和找到丢失值是两个不同的任务。不能仅凭重复的两个元素判断缺失数字。

## 三、方法一：计数数组

### 核心思想

创建长度为 n+1 的计数数组，其中下标 i 对应数字 i 的出现次数。

```cpp
cnt[nums[i]]++;
```

统计完成后：

* 出现 2 次的数字是重复值。
* 出现 0 次的数字是丢失值。

### 示例

```text
nums = [1, 2, 2, 4]

数字：      1  2  3  4
出现次数：  1  2  0  1
               ↑  ↑
             重复 丢失
```

### 复杂度

* 时间复杂度：O(n)
* 辅助空间复杂度：O(n)
* 是否修改原数组：否

这是最直观、最容易调试的方法。

## 四、方法二：数学求和

设重复值为 d，丢失值为 m。

正确总和：

S = n(n+1)/2

实际总和与正确总和之差：

A = d-m

正确平方和：

Q = n(n+1)(2n+1)/6

实际平方和与正确平方和之差：

B = d²-m² = (d-m)(d+m)

因此：

d+m = B/A

联立两个方程：

d = (A+B/A)/2

m = d-A

### 注意事项

使用 long long 保存总和和平方和，避免整数溢出。题目保证重复值和丢失值不同，因此 A 不为 0。

### 复杂度

* 时间复杂度：O(n)
* 辅助空间复杂度：O(1)
* 是否修改原数组：否

## 五、方法三：异或分组

### 第一步：整体异或

把实际数组和正确集合 1 到 n 的所有数字异或。

正常数字各出现两次，能够成对抵消，最终得到：

X = d ^ m

### 第二步：提取不同的二进制位

因为 d 和 m 不同，所以 X 不为 0。X 中为 1 的某一位，说明 d 和 m 在该位上不同。

使用：

```cpp
int lowbit = X & -X;
```

提取最低位的 1 作为分组依据。

### 第三步：按照该位分组异或

对实际数组和正确集合都使用同一套分组规则。

```cpp
if (x & lowbit) {
    a ^= x;
} else {
    b ^= x;
}
```

相同的正常数字进入同一组并抵消，而 d 和 m 因为选定的二进制位不同，必然进入不同组。

### 第四步：判断结果顺序

分组后得到的 a、b 只是两个候选数字，还不能确定谁重复、谁丢失。

再次扫描原数组：如果 a 在原数组中出现，则 a 是重复值；否则 b 是重复值。

### 示例

```text
实际数组：[1,2,2,4]
正确集合：[1,2,3,4]

X = 2 ^ 3 = 1
lowbit = 1
```

此时按最低位分组，相当于按奇偶分组。

奇数组：

```text
1 ^ 1 ^ 3 = 3
```

偶数组：

```text
2 ^ 2 ^ 4 ^ 2 ^ 4 = 2
```

得到候选数字 3 和 2，最后确定返回 `[2,3]`。

### 复杂度

* 时间复杂度：O(n)
* 辅助空间复杂度：O(1)
* 是否修改原数组：否

## 六、原地标记法补充

数字 x 对应下标 x-1。第一次遇到 x 时，把对应位置改为负数；再次遇到时，如果该位置已经为负，说明 x 重复。

最后仍为正数的位置对应丢失值。

读取数组元素时需要使用 abs，因为元素可能已经被修改为负数。可以在结束前恢复原数组。

该方法时间 O(n)，辅助空间 O(1)，但会暂时修改输入数组。

## 七、方法比较

| 方法   | 时间   | 辅助空间 | 修改原数组 |
| ---- | ---- | ---- | ----- |
| 计数数组 | O(n) | O(n) | 否     |
| 数学求和 | O(n) | O(1) | 否     |
| 异或分组 | O(n) | O(1) | 否     |
| 原地标记 | O(n) | O(1) | 暂时修改  |

位运算方法减少了辅助空间，但不保证实际运行时间一定比计数数组更短。复杂度相同的算法也可能有不同的常数开销。
