# 1705. 吃苹果的最大数目

## 核心

贪心 + 小根堆。

每天优先吃最早腐烂的苹果，否则它最容易浪费。

堆中保存：

```cpp
{expire, count}
```

其中 `expire = i + days[i]`，当：

```cpp
expire <= i
```

这批苹果已经不能吃。

## 每天流程

```text
加入今天新长的苹果
→ 清理过期批次
→ 取最早腐烂的一批吃 1 个
→ 有剩余则重新入堆
```

数组结束后仍要继续吃堆中未过期苹果。

## 易错点

访问 `q.top()` 前必须先判断：

```cpp
!q.empty()
```

正确顺序：

```cpp
!q.empty() && i >= q.top().first
```

时间复杂度约为 `O((n + ans) log n)`。
