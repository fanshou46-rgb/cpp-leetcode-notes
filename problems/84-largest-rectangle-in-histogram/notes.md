# 84. 柱状图中最大的矩形

## 核心知识

- 单调栈
- 左右双 0 哨兵
- 左右第一个严格更矮的位置
- 摊还复杂度

## 思路

只记录当前采用的“双哨兵”版本，不保留之前的方法。

在原柱状图左右各补一个高度为 0 的柱子：

```text
[2,1,5,6,2,3]
        ↓
[0,2,1,5,6,2,3,0]
```

- 左边的 0：保证弹栈后始终有合法的左边界。
- 右边的 0：在遍历结束前把栈中剩余柱子全部结算。

栈中保存下标，并保持对应高度单调不下降。

当：

```cpp
h[i] < h[st.top()]
```

说明栈顶柱子的右边第一个严格更矮的位置已经确定为 `i`。

弹出栈顶后：

- 右边界：`i`
- 左边界：新的 `st.top()`

所以：

```cpp
width = i - st.top() - 1;
area = height * width;
```

## 核心代码

```cpp
vector<int> h(n + 2, 0);
for (int i = 0; i < n; i++)
    h[i + 1] = heights[i];

stack<int> st;
st.push(0);

for (int i = 1; i < n + 2; i++) {
    while (h[i] < h[st.top()]) {
        int height = h[st.top()];
        st.pop();

        int width = i - st.top() - 1;
        ans = max(ans, height * width);
    }

    st.push(i);
}
```

## 为什么 while 用严格小于

相同高度不会阻止矩形继续向右延伸，所以只有遇到严格更矮的柱子时才结算：

```cpp
while (h[i] < h[st.top()])
```

## 复杂度

每个下标最多入栈一次、出栈一次：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
