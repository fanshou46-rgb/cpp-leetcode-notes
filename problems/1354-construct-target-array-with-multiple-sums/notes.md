# 1354 多次求和构造目标数组

## 核心知识

- 大根堆 priority_queue
- 逆向思维
- 贪心

## 思路

正向模拟会导致数字快速增大，因此采用逆向恢复。

当前数组中最大值一定来自最后一次操作。

设：
- x：当前最大值
- sum：当前数组总和
- rest：除最大值外的元素和

因为最后一次操作：

x = old + rest

所以：

old = x - rest

如果连续减很多次，可以使用：

old = x % rest

一次跳过重复过程。

每次取最大值，恢复后重新加入大根堆。

## 复杂度

时间复杂度：O(log n * k)

空间复杂度：O(n)
