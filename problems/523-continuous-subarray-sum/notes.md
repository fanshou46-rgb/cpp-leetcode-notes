# 523. 连续的子数组和

## 核心知识

- 前缀和取模
- 哈希表
- 相同余数
- 长度约束

## 思路

如果两个前缀和对 `k` 的余数相同：

```text
prefix[i] % k == prefix[j] % k
```

那么两者之差一定是 `k` 的倍数：

```text
(prefix[i] - prefix[j]) % k == 0
```

因此只要再次遇到相同余数，并且两个位置之间的距离至少为 2，就找到了满足条件的连续子数组。

哈希表保存每个余数第一次出现的位置。

初始化：

```cpp
mp[0] = -1;
```

表示数组开始前存在一个前缀和为 0 的空前缀。

## 核心模板

```cpp
unordered_map<int, int> mp;
mp[0] = -1;

long long sum = 0;

for (int i = 0; i < nums.size(); i++) {
    sum += nums[i];
    int r = sum % k;

    if (mp.count(r)) {
        if (i - mp[r] >= 2) {
            return true;
        }
    } else {
        mp[r] = i;
    }
}
```

## 为什么只保存第一次出现的位置

题目要求子数组长度至少为 2。

保留最早的位置可以让当前下标与它的距离最大，更容易满足长度要求，因此已经出现过的余数不要覆盖。

## 与 1590 的区别

- 523：寻找相同余数。
- 1590：寻找目标余数。
- 523 为满足长度约束保存第一次位置。
- 1590 为得到最短删除区间保存最近一次位置。

## 复杂度

- 时间复杂度：平均 `O(n)`
- 空间复杂度：`O(n)`
