# 1475. 商品折扣后的最终价格

## 核心思想

对每个商品，需要寻找右边第一个满足：

```cpp
prices[j] <= prices[i]
```

的位置 `j`。

直接向右扫描最坏为 `O(n^2)`。单调栈可以把它优化为 `O(n)`。

栈中保存“还没有找到折扣的商品下标”。当当前价格可以作为栈顶商品的折扣时，就立刻结算并弹栈：

```cpp
while (!st.empty() && prices[i] <= prices[st.top()]) {
    int j = st.top();
    st.pop();
    ans[j] = prices[j] - prices[i];
}
```

随后把当前下标压栈，等待未来元素解决。

## 为什么是单调栈

处理完每个元素后，栈中对应价格会保持单调关系。所有已经能被当前价格解决的元素都会被弹出，只留下仍在等待更合适右侧元素的位置。

## 复杂度

每个下标最多入栈一次、出栈一次：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 可迁移知识

看到“右边第一个更小/更大”“左边第一个更小/更大”这类问题时，应考虑单调栈。
