# 150. 逆波兰表达式求值

## 核心思想

逆波兰表达式天然适合使用栈：

```text
遇到数字 -> 入栈
遇到运算符 -> 弹出两个操作数 -> 计算 -> 结果重新入栈
```

数字 token 是字符串，可使用：

```cpp
stoi(x)
```

转换为整数。

## 操作数顺序

第一个弹出的数是右操作数，第二个弹出的数是左操作数：

```cpp
int b = st.top(); st.pop();
int a = st.top(); st.pop();
```

之后始终计算：

```text
a 运算符 b
```

这对减法和除法尤其重要。

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 可迁移知识

这是表达式计算类题目的经典栈模板：利用后进先出保证最近出现的操作数最先参与运算。
