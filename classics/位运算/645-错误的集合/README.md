# LeetCode 645：错误的集合

## 核心思想

这道题适合用来理解异或分组。

设重复值为 `d`，丢失值为 `m`。将实际数组与正确集合 `1...n` 中的所有数字全部异或，正常数字会成对抵消，最终得到：

```text
X = d ^ m
```

因为 `d != m`，所以 `X != 0`。取出 `X` 的最低位 `1`：

```cpp
int lowbit = X & -X;
```

这个二进制位一定能区分 `d` 和 `m`。随后按照这一位把实际数组和正确集合中的数字分成两组，并分别异或。相同的正常数字会进入同一组并抵消，而 `d` 和 `m` 会进入不同组，最终得到两个候选值。

最后再扫描原数组，判断哪个候选值出现过，即可确定重复值和丢失值的顺序。

## 关键知识

- `a ^ a = 0`
- `a ^ 0 = a`
- 异或满足交换律和结合律
- `x & -x` 可以提取最低有效位的 `1`
- 相同数字按照同一二进制位分组时一定进入同一组

## 复杂度

- 时间复杂度：`O(n)`
- 辅助空间复杂度：`O(1)`
- 不修改原数组
