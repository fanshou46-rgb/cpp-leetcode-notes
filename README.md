## 记录原则

简单题记在 daily，重点题单独整理到 problems，通用知识归档到 knowledge，代表性经典题额外进入 classics。保留自己的思路、真正有价值的错误原因和复杂度分析；小笔误不作为错误复盘重点，也不以单次运行时间或内存排名作为唯一优化标准。
